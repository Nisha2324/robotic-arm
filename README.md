# 3-DOF Robotic Arm

A 3-Degree-of-Freedom robotic arm designed using SOLIDWORKS, with CAD modeling of individual components and complete assembly.

## CAD Model

![3-DOF Robotic Arm](robotic-arm-main.png)

## Project Overview

This project focuses on the CAD design and assembly of a 3-DOF robotic arm. 
The arm consists of multiple mechanical components designed as individual parts and assembled together to form the complete robotic structure.

## Features

- 3 Degrees of Freedom (3-DOF)
- Individual mechanical part design
- Complete robotic arm assembly
- Gripper/end-effector design
- Servo-based joint structure
- CAD modeling using SOLIDWORKS

## CAD Components

The repository contains the following major components:

- Base
- Waist
- Link 1
- Link 2 / Link
- Link 3
- Servo components
- Gear
- Gripper
- End-effector
- Connecting links
- Complete robotic arm assembly

## Software Used

- SOLIDWORKS
